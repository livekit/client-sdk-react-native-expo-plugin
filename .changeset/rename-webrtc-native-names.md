Build against `@livekit/react-native-webrtc` 150.2.0, which renames its native classes so it can be installed in the same app as other react-native-webrtc forks. This release requires `@livekit/react-native` 3.2.0 or later and `@livekit/react-native-webrtc` 150.2.0 or later. Plugin versions 1.0.2 to 1.1.0 don't build against `@livekit/react-native-webrtc` 150.2.0, so update all three packages together.
