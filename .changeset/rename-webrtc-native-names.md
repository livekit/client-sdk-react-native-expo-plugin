Build against `@livekit/react-native-webrtc` 150.2.0, which renames its native classes so it can be installed in the same app as other react-native-webrtc forks. Update this plugin along with `@livekit/react-native` and `@livekit/react-native-webrtc`: plugin versions 1.0.2 to 1.1.0 don't build against 150.2.0, and this release doesn't build against earlier `@livekit/react-native-webrtc` versions.
